# DGES 2019 first-phase archive audit

## Question

The 2017-2026 broad-area Study A panel has one missing source year: 2019. Version 0.3.2 audits the official DGES 2019 statistics index to determine whether the standard first-phase archive exposes a complete broad-area placement table comparable to the locked 2017, 2018 and 2020-2026 tables.

## Official archive contents

The official 2019 first-phase index lists the following resource families:

1. placement summary;
2. 2018-2019 comparison by establishment;
3. 2018-2019 comparison by course;
4. application district/GAES, first choice and placement mobility;
5. general-contingent last-placed grades;
6. all establishment-course pair statistics;
7. the establishment-course pair statistics index.

No separate broad-area first-phase placement table is listed in that standard archive index.

The audit is recorded in `data/source_manifests/dges_2019_archive_audit.csv`.

## Consequence

The 2019 national totals remain source-locked, but they cannot identify the field composition required for the broad-area Study A series. Version 0.3.2 therefore changes the status of the gap from an open search for a standard archive table to an **audited standard-archive absence**.

This is not evidence that no compatible 2019 field information exists anywhere. In fact, the official course-comparison and establishment-course pair resources are valuable inputs for the programme-level panel. It only means that the current broad-area series cannot be completed by pretending the standard archive contains the same aggregate table as neighbouring years.

No 2019 STEM broad-area value is interpolated, reverse-engineered from national totals or inferred from programme subsets.

## Next use of the 2019 archive

The programme-level work should exploit the course-comparison and all-pair resources directly. That route also provides total candidates and entry-grade measures, which are needed for the registered applicants-per-vacancy analysis and cannot be recovered from the broad-area publication table.
